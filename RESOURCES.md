# Markov Models for Text Generation Resources

## Knowledge

- [N-grams and Markov Chains — decontextualize (Allison Parrish)](https://www.decontextualize.com/teaching/rwet/n-grams-and-markov-chains/)
  Excellent interactive tutorial with Python examples. Use for: core concepts, implementation patterns.
- [N-gram Language Models — Jurafsky & Martin (SLP3 Ch. 3)](https://web.stanford.edu/~jurafsky/slp3/3.pdf)
  The definitive textbook chapter on n-gram models. Use for: mathematical foundations, smoothing techniques.
- [N-gram Modeling With Markov Chains — Kevin Sookocheff](https://sookocheff.com/post/nlp/ngram-modeling-with-markov-chains/)
  Clean, minimal code examples for building n-gram models. Use for: reference implementation patterns.
- [Tutorial: Markov Chains with RiTa — rednoise.org](https://rednoise.org/rita/tutorials/ngrams.html)
  Visual explanation of Markov chain states and transitions. Use for: building intuition.
