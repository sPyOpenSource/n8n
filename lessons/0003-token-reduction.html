Token Reduction — The Sliding Window

Why Bother?

Every message costs tokens. opencode's agentic loops produce a lot of messages:

  • System prompt with AGENTS.md + LSP data: ~2,000 tokens
  • User asks to "fix this bug"
  • Assistant calls read_file, grep, edit — each is a message pair
  • Tool results come back as tool messages
  • 5–10 tool calls per turn, 10–20 turns per session = 50–200 messages

At ~100 tokens per message, that's 5,000–20,000 tokens just from conversation history — before the model generates a single response.

The Sliding Window

We never drop system prompts. Everything else gets a max length — keep the last N messages, drop the rest.

sys: you are... user: start asst: hello user: add login asst: tool_calls tool: results asst: done ...
user: fix bug asst: tool_calls tool: output asst: fixed

↓ Dropped ←             Window (last 15) →

The model gets the long system prompt + the last 15 messages. It can't see the old "add login" conversation — but it doesn't need to, it's already done.

Implementation

In server/prompt.py:

def trim_messages(messages: list[dict], max_messages: int = 15) -> list[dict]:
    if max_messages is None or not messages:
        return messages
    system = [m for m in messages if m.get("role") == "system"]
    non_system = [m for m in messages if m.get("role") != "system"]
    if len(non_system) <= max_messages:
        return messages
    trimmed = non_system[-max_messages:] if max_messages > 0 else []
    return system + trimmed

Called in server/api.py before the router:

max_msgs = config.get("MAX_MESSAGES", 15)
messages = trim_messages(messages, max_messages=max_msgs)

Configurable via environment or JSON config:

MAX_MESSAGES=30 python -m server.api   # keep last 30 messages

Key Insight: Why System Prompts Are Special

System prompts carry identity + instructions — without them, the model doesn't know what tools exist or how to behave. They must never be trimmed.

Everything else is conversation history — it's context for the current turn. Old turns are already done, the model doesn't need to re-read them.
