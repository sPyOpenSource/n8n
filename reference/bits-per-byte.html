Bits Per Byte (bpb)

Core Idea

bpb is the average number of bits needed to encode each byte of text, given the model's predictions. Lower is better. It's the byte-level analog of perplexity — tokenizer-independent, so you can fairly compare byte-level (vocab=256) and BPE (vocab=4,096) models.

bpb = −log₂ P(x) / |bytes| = cross-entropy (bits) ÷ bytes

With cross-entropy loss in nats (as frameworks report it):

bpb = loss_nats ÷ ln(2)   ·   (byte-level: 1 token = 1 byte)
perplexity per byte = 2^bpb

Random-Baseline Bound

Uniform guessing over 256 bytes: bpb = log₂(256) = 8. Any trained model should be well below 8.

Why bpb, Not Perplexity?

Perplexity is per-token. Tokens differ across tokenizers (1 BPE token = 1–6+ bytes). bpb divides by bytes — intrinsic to the text — enabling fair cross-tokenizer comparison. Proposed by Gao et al. (2020, The Pile).

Implementation Note
