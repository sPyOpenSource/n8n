Word-Level Markov Models

Reference — n-gram language models for text generation. See Lesson 1.

Core Idea

A Markov model predicts the next word based on the previous n-1 words. It assumes the Markov property: the next state depends only on the current state, not the full history.

P(wi | w1, w2, ..., wi-1) ≈ P(wi | wi-n+1, ..., wi-1)

N-gram Types

Name n Context Quality
Unigram 1 None Gibberish
Bigram 2 1 previous word Weak grammar
Trigram 3 2 previous words Decent fluency
4-gram 4 3 previous words Nearly verbatim

Algorithm

Training (build the model)
  1. Tokenize corpus into word sequences
  2. Slide a window of size n over each sequence
  3. Count: for each context (first n-1 words), how many times each next word appears
  4. Normalize counts into probabilities (optional — sampling uses raw counts directly)
Generation (sample from the model)
  1. Pick a starting context (or use BOS tokens)
  2. From current context, look up possible next words and their counts
  3. Randomly sample one proportional to its count
  4. Slide context: drop the first word, append the sampled word
  5. Repeat until EOS or max length

Implementation (Python)

from collections import defaultdict, Counter
import random

class WordMarkov:
    def __init__(self, n=3):
        self.n = n
        self.model = defaultdict(Counter)  # context -> {word: count}

    def train(self, corpus):
        for tokens in corpus:
            ctx = tuple([''] * (self.n - 1))
            for word in tokens + ['']:
                self.model[ctx][word] += 1
                ctx = ctx[1:] + (word,)

    def generate(self, max_len=50):
        ctx = tuple([''] * (self.n - 1))
        out = []
        for _ in range(max_len):
            counts = self.model.get(ctx, {})
            if not counts:
                break
            words, weights = zip(*counts.items())
            word = random.choices(words, weights=weights, k=1)[0]
            if word == '':
                break
            out.append(word)
            ctx = ctx[1:] + (word,)
        return ' '.join(out)

Key Parameters

  • n (order): higher = more fluent but less diverse. n=3 is the sweet spot for story generation.
  • Temperature (optional): flatten (t > 1) or sharpen (t < 1) the probability distribution.
  • Max length: cap generation to avoid infinite loops.

Strength & Weaknesses

Strength Weakness
Fast to train (seconds on 2M docs) No long-range dependencies
Fast to generate (10K in <1s) Needs smoothing for unseen n-grams
Interpretable and debuggable Cannot generalize beyond training data

Smoothing

When a context was never seen in training, the model returns an empty count dictionary. Solutions:

  • Backoff: fall back to lower-order n-gram (e.g., n=3 → n=2)
  • Add-k smoothing: add a small constant to all counts
  • Interpolation: weighted average of all order predictions
